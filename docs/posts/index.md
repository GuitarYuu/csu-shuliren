  <li data-i18n="note.2">LaTeX 行内公式用 <code>$...$</code>、独立公式用 <code>$$...$$</code>，代码用三反引号围栏；</li>

  <li data-i18n="note.6">文章底部评论区支持评论与点赞，需<strong>登录 GitHub 账号</strong>后操作；</li>
